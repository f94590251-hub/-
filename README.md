# AI 콘테스트: 마크 안에서 마크

AI를 이용해 신기하고 재밌는 마인크래프트 맵이나 영상을 만들어보세요!

이 저장소는 사용자가 말한 “마크 안에서 마크 할 수 있는 그런 것”을 바닐라 데이터팩으로 구현하는 기술 시연용 예시입니다. 리소스팩 없이 명령어와 데이터팩만으로 실제 마인크래프트 안에 또 하나의 가짜 마인크래프트 시작 화면, 싱글플레이/멀티플레이 메뉴, 월드 만들기 화면, 평지/기본 설정, 월드 생성 후 채굴·조합·설치 루프를 흉내 냅니다.

## 버전

- 대상: Minecraft Java Edition 1.20.3/1.20.4
- 데이터팩 `pack_format`: 26
- 리소스팩: 사용하지 않음

## 참가 규칙

- 아이디어를 제외한 구현 과정은 100% AI를 활용해야 합니다.
- 사람의 손길이 닿은 수작업 구현은 허용되지 않습니다.
- 리소스팩 사용은 금지됩니다.
- 데이터팩과 명령어만 사용해 바닐라 마인크래프트에서 동작해야 합니다.

## 구현 콘셉트

“마크 안에서 마크”는 실제 월드 안에서 다시 작은 마인크래프트를 켜는 느낌의 미니 시뮬레이션입니다.

1. `/function mcmine:start`를 실행하면 채팅 UI와 타이틀로 `MINECRAFT` 창이 켜집니다.
2. 시작 화면에서 `싱글플레이`, `멀티플레이`, `설정`, `종료` 버튼처럼 보이는 클릭 가능한 텍스트가 나옵니다.
3. `싱글플레이`에 들어가면 `새 월드 만들기` 화면으로 이동할 수 있습니다.
4. 월드 만들기에서는 `기본` 또는 `평지` 월드 유형을 고른 뒤 `맵 생성`을 누릅니다.
5. 맵 생성이 끝나면 미니 월드 플레이 모드가 켜지고 채굴·조합·설치를 할 수 있습니다.

## 플레이 조작

월드 생성 후 아래 버튼 또는 명령어로 플레이합니다.

- `/trigger mcmine.mine`: 미니 월드에서 돌을 채굴합니다.
- `/trigger mcmine.craft`: 돌 3개를 모아 미니 곡괭이를 조합합니다.
- `/trigger mcmine.place`: 미니 월드의 돌 1개를 플레이어가 바라보는 방향 앞쪽에 설치합니다.
- 액션바에는 현재 돌과 곡괭이 수가 표시됩니다.

## 사용 방법

1. 이 저장소 폴더를 월드의 `datapacks` 폴더에 넣습니다.
2. 월드에 들어가 `/reload`를 실행합니다.
3. `/function mcmine:start`로 마크 안의 가짜 마크 창을 엽니다.
4. 채팅에 표시되는 버튼을 눌러 `싱글플레이` → `새 월드 만들기` → `기본/평지 선택` → `맵 생성` 순서로 진행합니다.
5. 생성된 미니 월드에서 채굴, 조합, 설치를 반복합니다.
6. 맵 범위를 제한하려면 `/function mcmine:map_limit`을 실행합니다.
7. 맵 범위를 해제하려면 `/function mcmine:clear_map_limit`을 실행합니다.
8. 종료하려면 `/function mcmine:stop`을 실행합니다.
