# AI WORLD — Long Campaign

AI 콘테스트용 바닐라 Minecraft 기술 시연/장편 캠페인 기반입니다.

## 현재 브랜치
`ai-world-long-campaign`

## 포함된 기반 시스템
- AI WORLD 시작 연출
- Chapter 1~6 진행 상태 scoreboard
- 인게임 게임 메뉴 트리거 (`/trigger ai_menu set 1`)
- AI 도움말 함수
- 특수 발전과제
- AI CORE 최종 챕터
- 단일 엔딩 방향
- 리소스팩/모드 없이 데이터팩과 명령어 기반

## 캠페인 구조
1. 잊혀진 숲
2. 지하 AI 연구소
3. AI 마을
4. 네더 실험구역
5. 오류 세계
6. AI CORE
7. 단일 FINAL

> 실제 Minecraft 클라이언트의 ESC 메뉴와 싱글플레이 저장 목록은 데이터팩이 직접 교체할 수 없습니다. 따라서 게임 내부에서 구현 가능한 메뉴/진행 시스템은 데이터팩으로 제공하고, 클라이언트 전용 기능은 바닐라 Minecraft에 맡깁니다.
