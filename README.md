# AI 제작 공포 탈출 맵

이 저장소는 **AI로 제작된 공포 탈출 맵**의 구현 사양을 정리합니다. 실제 맵 제작자가 바로 이벤트, 아이템, 엔딩, 발전 과제를 옮길 수 있도록 `data/ai_horror_escape_map.json`에 구조화된 설정도 함께 제공합니다.

## 시작 안내 문구

맵 시작 즉시 플레이어 화면 중앙에 다음 문구를 순서대로 표시합니다.

1. `이 맵은 AI로 전부 제작되었습니다.`
2. `갑작스러운 점프스케어, 큰 효과음, 속삭임, 깜빡이는 조명, 추격 연출이 포함되어 있습니다.`
3. `이어폰 착용 시 볼륨을 낮추고 플레이해 주세요.`
4. `목표: 흔적을 따라 열쇠를 찾고 시설에서 탈출하세요.`

## 필수 구현 요소

- 👻 갑자기 튀어나오는 점프스케어
- 🔊 갑작스러운 효과음과 좌우 채널 속삭임
- 🕯️ 불이 꺼졌다 켜지는 정전/비상등 연출
- 🚪 플레이어 입력 없이 혼자 열리고 닫히는 문
- 👁️ 멀리서 잠깐 나타났다가 사라지는 괴물
- 🩸 핏자국과 긁힌 자국을 따라가는 추적 구간
- 🌀 트리거에 따라 길이 바뀌는 미로
- 😨 플레이어가 뒤돌아보면 나타났다가 다시 보면 사라지는 형체
- 🔑 열쇠와 카드키를 찾아 최종 출구를 여는 탈출 스토리
- 💀 일반 진행 기준 75분 이상, 비밀 요소 포함 시 90분 이상 플레이타임
- 🏆 여러 발전 과제
- 🎭 일반, 배드, 히든, 진, 개그 엔딩

## 챕터별 진행

| 챕터 | 예상 시간 | 목표 |
| --- | ---: | --- |
| 프롤로그: AI의 안내 | 5분 | 시작 경고 확인, 폐쇄 시설 진입, 첫 이상 현상 목격 |
| 1장: 폐쇄된 로비 | 10분 | 로비 열쇠 획득, 혼자 열리는 문 조사, 관리자 메모 수집 |
| 2장: 연구동 | 15분 | 실험 기록 3개 수집, 연구동 카드키 획득, 괴물 첫 목격 |
| 3장: 정전 구역 | 10분 | 발전기 2대 복구, 깜빡이는 조명 구간 통과, 비상 통로 개방 |
| 4장: 피의 흔적 | 10분 | 핏자국 루트 추적, 숨겨진 방 발견, 지하실 열쇠 획득 |
| 5장: 변형 미로 | 15분 | 바뀌는 길 파악, 미로 중앙 암호 획득, 추격 이벤트 생존 |
| 6장: 탈출 또는 잔류 | 10분 이상 | 최종 문 개방, 수집 단서에 따른 선택, 엔딩 확인 |

## 데이터 파일

구현용 상세 설정은 다음 파일에 있습니다.

- `data/ai_horror_escape_map.json`: 시작 문구, 챕터, 공포 이벤트, 수집 아이템, 발전 과제, 엔딩 조건을 담은 구조화 데이터

## 엔딩 분기 요약

- **일반 엔딩: 탈출** — 최종 출구 열쇠만 사용해 시설을 빠져나갑니다.
- **배드 엔딩: 실험체** — 핵심 단서가 부족한 상태로 탈출을 시도하면 실험체가 됩니다.
- **히든 엔딩: AI와의 계약** — 글리치 방과 비밀 코드를 찾으면 AI와 계약합니다.
- **진엔딩: 제작자의 방** — 모든 로그를 모으면 AI의 목적과 괴물의 정체가 밝혀집니다.
- **개그 엔딩: 전원 차단** — 모든 발전기를 끄고 관리실 차단기를 내리면 공포 연출이 멈춥니다.
