# AI 콘테스트: 마크 안에서 마크

AI를 이용해 신기하고 재밌는 마인크래프트 맵이나 영상을 만들어보세요!

이 저장소는 사용자가 말한 “마크 안에서 마크 할 수 있는 그런 것”을 바닐라 데이터팩으로 구현하는 기술 시연용 예시입니다. 리소스팩 없이 명령어와 데이터팩만으로 채굴, 조합, 설치 루프를 미니 게임처럼 흉내 냅니다. 이번 버전은 성공/실패 판정을 분리해 자원이 충분할 때 실패 메시지가 함께 뜨지 않도록 다시 정리했습니다.

## 버전

- 대상: Minecraft Java Edition 1.20.3/1.20.4
- 데이터팩 `pack_format`: 26
- 리소스팩: 사용하지 않음

## 참가 규칙

- 아이디어를 제외한 구현 과정은 100% AI를 활용해야 합니다.
- 사람의 손길이 닿은 수작업 구현은 허용되지 않습니다.
- 리소스팩 사용은 금지됩니다.
- 데이터팩과 명령어만 사용해 바닐라 마인크래프트에서 동작해야 합니다.

## 구현 콘셉트

“마크 안에서 마크”는 실제 월드 안에서 다시 작은 마인크래프트 규칙을 플레이하는 느낌의 미니 시뮬레이션입니다.

- `/trigger mcmine.mine`: 미니 월드에서 돌을 채굴합니다.
- `/trigger mcmine.craft`: 돌 3개를 모아 미니 곡괭이를 조합합니다.
- `/trigger mcmine.place`: 미니 월드의 돌 1개를 플레이어가 바라보는 방향 앞쪽에 설치합니다.
- 액션바에는 현재 돌과 곡괭이 수가 표시됩니다.

## 사용 방법

1. 이 저장소 폴더를 월드의 `datapacks` 폴더에 넣습니다.
2. 월드에 들어가 `/reload`를 실행합니다.
3. `/function mcmine:start`로 미니 마크를 시작합니다.
4. 아래 명령어를 반복하며 플레이합니다.
   - `/trigger mcmine.mine`
   - `/trigger mcmine.craft`
   - `/trigger mcmine.place`
5. 맵 범위를 제한하려면 `/function mcmine:map_limit`을 실행합니다.
6. 맵 범위를 해제하려면 `/function mcmine:clear_map_limit`을 실행합니다.
7. 종료하려면 `/function mcmine:stop`을 실행합니다.
