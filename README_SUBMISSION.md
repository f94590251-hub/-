# AI Minecraft Menu — v5 Submission

데이터팩/명령어만으로 Minecraft 내부에서 Minecraft 스타일의 메뉴와 세계 생성 흐름을 재현하는 기술 시연.

## 실행

1. 데이터팩을 월드의 `datapacks` 폴더에 넣습니다.
2. `/reload`
3. `/function aimenu:submit_v5_clean`
4. 싱글플레이 → 새로운 세계 만들기
5. 게임/세계/기타 설정을 선택합니다.
6. 생성 버튼으로 로딩 연출을 시작합니다.

## 시연 포인트

- Minecraft 스타일 메인 메뉴
- 싱글플레이/새로운 세계 만들기 흐름
- 게임 모드 및 난이도 선택
- 소지품 유지/자연 재생/몹 생성 설정
- 0% → 25% → 60% → 100% 세계 생성 연출
- 선택한 설정을 실제 gamemode/difficulty/gamerule에 적용
- 생성 완료 후 플레이 진입

## 대회 조건 관련

리소스팩 없이 데이터팩과 명령어만 사용합니다. 클라이언트의 실제 Minecraft GUI나 실제 엔진 월드 생성 진행률을 변경하는 것이 아니라, 바닐라 텍스트 컴포넌트와 명령어로 동일한 사용자 흐름을 기술적으로 재현합니다.
